Notemark APT repository

Signed packages for Debian, Ubuntu, Linux Mint and Pop!_OS. This address is read by apt, not meant for browsing. The product page is at notemark.forhad.me.

Add the repository

curl -fsSL https://notemark.forhad.me/apt/notemark.gpg | sudo tee /usr/share/keyrings/notemark.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/notemark.gpg] https://notemark.forhad.me/apt stable main" | sudo tee /etc/apt/sources.list.d/notemark.list
sudo apt update
sudo apt install notemark

Remove it

sudo apt remove notemark
sudo rm /etc/apt/sources.list.d/notemark.list /usr/share/keyrings/notemark.gpg

Files

  • notemark.gpg and notemark.asc: the signing key (binary and armored)
  • dists/stable/InRelease: the signed index apt reads
  • GitHub releases: the same packages as a plain .deb, AppImage and tarball
