Notemark APT repository

Add the repository once and Notemark updates with the rest of your system. This address is read by apt; the product page is at notemark.forhad.me.

1Add the repository and install

Terminal
curl -fsSL https://notemark.forhad.me/apt/notemark.gpg | sudo tee /usr/share/keyrings/notemark.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/notemark.gpg] https://notemark.forhad.me/apt stable main" | sudo tee /etc/apt/sources.list.d/notemark.list
sudo apt update && sudo apt install notemark

The first line saves the signing key, the second adds the source, the third installs.

2Update later

Terminal
sudo apt update && sudo apt upgrade

Remove it

Terminal
sudo apt remove notemark
sudo rm /etc/apt/sources.list.d/notemark.list /usr/share/keyrings/notemark.gpg
